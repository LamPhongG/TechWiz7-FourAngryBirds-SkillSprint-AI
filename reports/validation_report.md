## 3. Mandatory vs. Optional Requirement Tracking

### 3.1 Mandatory Requirements
Mandatory requirements represent high-stakes compliance and legal obligations (e.g., GDPR data handling, fire safety protocols, dual-signoff authorization thresholds, probation review milestones). 
- **Rule Enforcement**: The Python rule engine enforces that no onboarding plan may be published or assigned if any mandatory requirement has a status of `MISSING` or `UNSUPPORTED`.
- **Resolution Flow**: Missing mandatory items automatically trigger an automated remediation step: the system attempts targeted regeneration using an elevated-temperature prompt with explicit citation anchoring; if unresolved, the item is escalated to the Reviewer dashboard.

## 5. Contradiction Analysis & Superseded Document Handling

SkillSprint AI maintains temporal awareness to handle conflicting versions of corporate policies.

### 5.1 Document Supersession Logic
When both `DOC-01 (Employee Handbook v2.0)` and `DOC-02 (Employee Handbook v1.0)` exist in the repository:
- The system checks document metadata: `DOC-01` has `version: 2.0`, `status: active`; `DOC-02` has `version: 1.0`, `status: superseded_by: DOC-01`.
- Any requirement claim derived exclusively from `DOC-02` without concordance in `DOC-01` is marked `SUPERSEDED_OUTDATED`.

### 5.2 Adversarial Contradiction Test Cases (CTX Series)
During audit testing against the 10 adversarial injection documents:
1. **CTX-01 (Old Leave Memo)**: Attempted to grant 25 annual leave days. *Result*: Blocked; active `DOC-03` specifies 14 days.
2. **CTX-03 (Inflated Sales Deal Threshold)**: Claimed VP approval needed only above $500,000. *Result*: Blocked; active `DOC-08` enforces $50,000 threshold.
3. **CTX-04 (IT Access Bulletin Self-Contradiction)**: Contained contradictory password expiration intervals (30 days vs 180 days). *Result*: Flagged for manual review with ambiguity warning.
4. **CTX-05 (Corporate Card Threshold)**: Claimed card limit of $10,000 without receipt. *Result*: Intercepted by threshold validator.
