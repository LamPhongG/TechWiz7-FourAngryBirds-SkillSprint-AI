# Information Security & Access Policy

## 1. Password Management & Authentication
Passwords must be at least 12 characters, including upper, lower, numbers, and symbols. Multi-factor authentication (MFA) is mandatory for all internal accounts.

## 2. Device Security & Clean Desk Policy
Workstations must be locked whenever unattended. Sensitive documents must not be left on desks overnight.

## 3. Cloud Storage & Removable Media Restrictions
Storing company confidential files on personal cloud accounts (Google Drive, Dropbox) or unapproved USB drives is strictly prohibited.

## 4. Secure Customer Data Access [MANDATORY]
Staff handling customer issues must access customer data only through approved, logged tooling during escalation handling. Direct database export or raw query execution on customer databases is strictly prohibited.

## 5. Security Incident Escalation
Any phishing email, security vulnerability, or credential leak must be forwarded immediately to security@fourangrybirds.vn.
